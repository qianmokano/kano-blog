欢迎来到我的个人博客。

这里主要记录软件开发中的思考、项目实践和持续学习，也会放下一些不够长、但值得留存的笔记。

这个站点使用 Astro、TypeScript 和 MDX 构建。文章保存在 Git 仓库中，搜索索引由 Pagefind 在构建时生成，评论则交给 GitHub Discussions。它刻意保持简单：没有数据库，没有内容后台，也没有为了动效而引入整套前端框架。

希望这里的内容能对未来的我，以及偶然来到这里的你有所帮助。
